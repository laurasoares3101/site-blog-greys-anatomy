## Sobre o projeto

O Plantão Grey's é um blog de fãs da série Grey's Anatomy. O site reúne informações sobre a história da série, seus personagens, curiosidades e o universo do hospital Grey Sloan Memorial. O objetivo é apresentar o conteúdo de forma organizada, utilizando cinco páginas desenvolvidas em HTML.

## Como abrir o projeto

1. Baixar os arquivos do projeto.
2. Abrir a pasta no Visual Studio Code.
3. Localizar o arquivo `index.html`.
4. Abrir o arquivo no navegador.

## Páginas do site

- `index.html`: página inicial, com a apresentação do blog e da série.
- `sobre.html`: informações sobre a série, sua história e termos médicos.
- `dados.html`: tabela com informações sobre personagens e especialidades.
- `cadastro.html`: formulário para os visitantes registrarem suas preferências.
- `contato.html`: informações e formulário para entrar em contato com o blog.

## Acessibilidade

- Idioma da página definido como português do Brasil.
- Imagens com descrição alternativa (`alt`).
- Campos dos formulários associados às suas etiquetas (`label`).
- Link para pular diretamente ao conteúdo principal.
- Conteúdo organizado com elementos semânticos do HTML.
- Navegação pelas páginas utilizando o teclado.

### Teste de teclado

O teste foi realizado nas cinco páginas utilizando as teclas Tab e Enter. Foi possível navegar pelos links, menus e campos dos formulários sem utilizar o mouse.
